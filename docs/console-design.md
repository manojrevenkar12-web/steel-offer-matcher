# Console design notes

Subject: a steel trader's review desk. Audience: traders checking what the platform read and offered. Primary job: decide
quickly and trust the evidence.

- Colour: galvanised grey page, mill-scale ink, one action blue; status in patina green, amber and oxide red. The one bold
  element is chalk yellow, used only to mark the text each value was read from, like a paint marker on a coil.
- Type: Barlow for text, Barlow Condensed for dimensions and headings, tabular numbers throughout.
- Layout: inbox, the email with its evidence marks, and the lines with offers. Hovering a value marks its quote.
- Offers are drawn as coil tags: dimensions first, grade, usable tonnes, origin, landed price; opening a tag lists every check.
- Motion: one staggered reveal of the inbox; offers open with a height transition; reduced motion is respected.
- Every screen has a loading skeleton, an error with a retry, and an empty state that says what to do.
